# portfolio

Source for [portfolio.rocknroll17.com](https://portfolio.rocknroll17.com).

Content is written in Notion. GitHub Actions rebuilds the site every hour as a
static export and deploys it to GitHub Pages, styled to match
[cv.rocknroll17.com](https://cv.rocknroll17.com).

Built on [nextjs-notion-starter-kit](https://github.com/transitive-bullshit/nextjs-notion-starter-kit) (MIT, see `license`).

```bash
pnpm install
pnpm next build   # output in out/
```
